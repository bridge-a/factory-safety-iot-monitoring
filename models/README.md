# 明火检测模型

软件使用第三方预训练 YOLOv8n 权重，不是本项目自行训练的模型。实际文件不提交 Git，部署包可携带已校验的同一文件，也可由启用脚本下载。

- 来源：[fiacecson20/cctv-ai-fire-smoke](https://huggingface.co/fiacecson20/cctv-ai-fire-smoke)。
- 固定版本：`343990e42d99a5d27e9f35fc7c80880dc5f43f45`；精确地址、大小与 SHA-256 见 [清单](fire-model.json)。
- 实际检查：输入 `float32[1,3,320,320]`，输出 `[1,6,2100]`，类别 `0=fire, 1=smoke`；YOLOv8 无 objectness，导出未包含 NMS。
- 本系统只处理 fire 类，烟雾报警仍由 MQ-2 相对读数判断。模型的 smoke 输出不当作 MQ-2 读数。
- 上游模型卡描述为 320 尺寸、12 轮训练的早期模型，不能据此承诺本装置识别率。上游训练数据说明链接未能完整核实，项目不将其宣传为自建数据集或自训练结果。
- 许可存在不同标记：模型卡称权重 MIT，ONNX 内嵌元数据标注 AGPL-3.0。两项标记均保留，详见 [第三方声明](../THIRD_PARTY_NOTICES.md)。本项目不将该模型重新标为独占或原创权重。

在小玻璃罩内的火焰、反光、LED、暖色物体和屏幕视频均需单独验证。使用屏幕火焰视频可以验证软件流程，但不能替代实际场景识别测试。
