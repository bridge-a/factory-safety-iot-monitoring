# 历史趋势页改版

日期：2026-10-12。属于 `main` 开发版，视觉效果待确认；最近发布标签仍为 v0.1.0。

## 调整目标

原页面的重复标题、四张独立统计卡和侧边查询面板占据较多首屏空间。本轮将常用操作集中到顶部，让趋势图成为主要阅读区域，保持监控总览与告警页已经认可的青绿配色。

![历史趋势页，使用隔离模拟采样](images/history.png)

该截图来自验证脚本生成的模拟数据。峰值仅用于检查图表展示，不代表真实烟雾测试。

## 设计取舍

- 沿用告警页的文字导航、简洁顶栏与实时风险指示，页面保留一个主标题。
- 模式、快捷范围和自选时段集中在一栏；查询历史模式与后台当前运行模式独立。
- 温度、湿度、CO₂、烟雾直接切换，同时更新单位、统计、阈值说明与明细中的对应列。
- 平均值、最高值、最低值和采样数合并在图表内，取消四张独立统计卡及查询侧栏。
- 趋势线使用青绿色，演示阈值使用低饱和的黄、红虚线；图表保留缺失点的断开，不用零值或平滑线填补。
- 表格数字右对齐、单位放在列标题，所选指标列轻量高亮，数据模式始终标注。
- 自选时间支持 Enter 应用、Esc 关闭和点击外部关闭。最长查询范围保持 24 小时。
- 加载、无采样、单指标全缺失、查询失败分别展示；切换查询时清空旧统计，晚到的旧响应不会覆盖新选择。
- CSV 使用页面已加载的时间边界，导出全部采样，缺失值保持空白。

设计参考：[shadcn-admin](https://github.com/satnaing/shadcn-admin) 的简洁导航与内容层次、[Grafana](https://grafana.com/docs/grafana/latest/visualizations/dashboards/use-dashboards/) 的集中时间范围控件、[Ant Design](https://ant.design/docs/spec/visualization-page/) 的图表优先级与细节组织。没有引入这些项目的前端框架或模板代码。

## 验证

运行独立浏览器检查：

```powershell
.\.venv\Scripts\python.exe tests/history_ui_check.py
```

脚本使用隔离数据库及明确的模拟数据，不发送外部邮件，也不代表硬件链路已经验收。截图与 JSON 结果写入被忽略的 `artifacts/history-check/`。

- 1366、1920、768、390 像素宽度无整页横向溢出。
- 1366 × 768 下趋势图位于约 435～715 像素高度，曲线与坐标轴在首屏内完整显示。
- 四指标切换同步更新统计、单位、阈值及采样列。
- 900 条查询采样降采样绘图后，统计和 CSV 仍使用全部 900 条；空值不变成零。
- 自选时间校验、空状态、查询失败重试、加载状态与响应顺序检查通过。
- 告警页和全站回归结果记录在 [验证记录](VALIDATION.md)。

下一步先确认本页效果，再依次整理明火检测、设备管理和模拟与联调页。
