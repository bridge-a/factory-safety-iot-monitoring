## 2026-10-15：四传感器串口测试程序（main）

- 新增 `firmware/sensor_check/sensor_check.ino`，使用 GPIO8/9 的 I²C 和 GPIO4 的分压后模拟输入。程序只读传感器并输出串口，不启动 Wi-Fi / MQTT，不修改后台数据。
- 使用 Arduino CLI 1.1.1、esp32 core 3.0.7 与既有传感器库，在 `esp32:esp32:esp32s3:CDCOnBoot=cdc` 编译通过。程序 340713 字节，全局变量 19264 字节。
- 系统与 Arduino CLI 只读发现 `COM3`，USB VID/PID 为 `303A:1001`，识别为 ESP32 Family Device；仍不能据此确定具体板型、Flash / PSRAM 参数。
- 程序输出 I²C 地址应答、有效温湿度/光照、CO₂ 新值/缓存年龄/过期状态，以及 MQ-2 ADC 平均值/极值/电压；不把单纯 ADC 读数标为传感器正常，也不自动宣布预热完成。
- 本轮未烧录或读取实物输出，尚不能确认各传感器工作正常。原旧草图在本轮检查期间哈希未变，工厂联网固件与网页实现未修改；构建产物由 Git 忽略。

操作方法与读数含义见 [串口测试说明](../firmware/sensor_check/README.md)。

## 复现方式

在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
New-Item -ItemType Directory -Force .test-tmp | Out-Null
$qaTempPath = Join-Path '.test-tmp' ([guid]::NewGuid().ToString('N'))
.\.venv\Scripts\python.exe -m pytest -q --basetemp=$qaTempPath
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe tests/browser_check.py
.\.venv\Scripts\python.exe tests/alerts_ui_check.py
```

Linux 使用 `.venv/bin/python`；后端测试可以执行 `.venv/bin/python -m pytest -q`。Linux 首次安装浏览器时，可使用 `.venv/bin/python -m playwright install --with-deps chromium` 安装系统依赖。

浏览器检查生成的截图和 JSON 报告分别位于 `artifacts/browser-check/`、`artifacts/alerts-check/`，均不提交。README 仅保留少量明确标为模拟数据的展示截图。
