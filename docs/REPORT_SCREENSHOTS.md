共 35 张图片：3 张真实原图、32 张模拟占位图。正文优先使用真实正常总览、真实明火报警总览和真实告警邮件，再选取各功能页与关键详情图。其余图片可作备选，避免同一功能重复堆图。模拟图保留“报告占位”标记，可在后续测试后按同名文件替换为实机截图；模拟数值不作为实测结果。

真实明火截图记录的是摄像头拍摄手机火焰视频的回放联调；其中的检测置信度不是模型准确率。

邮件图适合作为“QQ 邮箱远程告警接收”配图：事件 #24，发生时间 2026-10-15 23:22:24（北京时间），设备 `workshop1:vision`，红色报警，事件置信度 83%。该时间与真实报警总览中的事件相符；邮件展示触发时记录，总览中的实时置信度可能随后续帧变化。

## 重新生成

使用已安装开发依赖和 Playwright Chromium 的本地 Python 环境：

```powershell
.venv\Scripts\python.exe tools/capture_report_screenshots.py
```

原始图片默认从当前用户的 `AppData/Local/Temp` 读取。如已移走，保留原始文件名，并指定其目录：

```powershell
.venv\Scripts\python.exe tools/capture_report_screenshots.py --real-dir "D:\report-originals" --out "D:\report-images"
```

工具使用项目实际页面与独立 SQLite 测试数据，在本地临时端口渲染截图。不会启动监测后台，不连接 MQTT、物理摄像头或 SMTP。摄像头画面由工具绘制为明确标注的示意图，连接、检测和声光状态均为模拟；真实原图按字节复制，不修改内容。

生成时检查六页、报警等级、详情可见性、页面横向溢出和浏览器脚本错误。图片适合报告插图，采用 1920 像素 CSS 视口、1.5 倍像素密度；较长页面扩展高度，详情另提供局部图。

图片、截图测试数据库和压缩包都属于本地材料，由 `.gitignore` 排除。GitHub 只保存生成工具与说明，不上传用户截图或本地运行数据。
