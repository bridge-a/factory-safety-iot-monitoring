# 树莓派明火模型接入

适用环境：用户已确认的 Raspberry Pi 5 / 8GB、aarch64、Python 3.11.2；项目目录 `/home/pi/factory_monitoring`。现有 USB 摄像头和 180° 画面旋转继续使用。

## 上传与启用

1. 在运行网页后台的终端按 `Ctrl+C`，停止本项目后台。
2. 将本地 `vision_update` **里面的文件和子目录**合并到 `/home/pi/factory_monitoring/`。例如，`vision_detector.py` 应直接位于项目根目录；`models/fire_yolov8n.onnx` 位于项目的 `models` 内。不要再套一层 `vision_update`。
3. 不上传 `.venv`、`runtime.env`、`mail.ini`、`data`；已有 Wi-Fi/MQTT、邮件、旋转配置保持原样。
4. 在树莓派一次复制下面这一整行，等待安装和模型检查完成：

```bash
cd /home/pi/factory_monitoring && bash deploy/raspberry-pi/enable-vision.sh && bash deploy/raspberry-pi/run.sh
```

首次安装需要联网下载 CPU 推理依赖。ONNX Runtime 1.23.2 提供 CPython 3.11 / aarch64 wheel；脚本仅接受二进制依赖，不在树莓派上编译训练框架。约 12MB 模型若已上传且校验正确，不再下载。脚本先检查模型、执行空白测试帧推理，再备份和更新 `FACTORY_VISION_ENABLED`；其他配置保留。

如果启用失败，可继续用 `bash deploy/raspberry-pi/run.sh` 启动原有监控，并保留终端错误供排查。模型加载失败不会停止环境采样、历史和邮件线程。

## 默认行为

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `FACTORY_VISION_ENABLED` | 0；启用脚本改为 1 | 是否启动视觉后台 |
| `FACTORY_VISION_FPS` | 2 | 检测目标频率；界面显示最近实际完成帧率 |
| `FACTORY_VISION_CONFIDENCE` | 0.55 | 单框最低置信度 |
| `FACTORY_VISION_CONFIRM_SECONDS` | 1.5 | 连续疑似明火至少持续此时长，且至少 3 个不同帧才报警 |

先用默认参数完成闭环，再根据实测改参数。数值不是经过工业验证的安全阈值。

- 复用单个摄像头采集线程的最新 JPEG，使用旋转后的画面推理；不会第二次打开摄像头。
- CPU 仅使用两个推理线程，队列不堆积旧帧。推理与 MQTT、采样和邮件相互独立。
- 启用后预览显示**模型处理过的同一帧及标框**，更新速度随检测帧率，默认约 2 FPS 上限。模型未就绪时仍可显示原始摄像头画面，旁边明确显示检测异常或未启用。
- 模型只确认明火；烟雾与环境指标继续独立判断，不要求同时异常。
- 摄像头是真实来源，在 demo / hybrid / live 三种环境模式下都保持实际采集属性。模式选择只控制环境传感器模拟，明火事件可发送真实邮件。
- 确认明火后：综合风险红色、事件持久化、网页弹窗、QQ 邮件队列、现有 ESP32 声光控制。声光指令依赖在线 ESP32 与有效上报令牌。
- 同一持续异常只记一次；连续 15 秒有效无火画面才记录恢复。没有画面、重复旧帧、模型错误不算恢复，之前的报警保持到有效恢复。
- 截图使用触发时的标框帧，最多保留最近 200 张 JPEG，保存在 `data/vision/events/`。旧截图清理不删除 SQLite 事件。邮件包含置信度与原因，截图在网页事件详情查看。
- 关闭网页后仍检测，停止后台进程则全部监测停止。

## 实机验证顺序

1. 刷新网页（必要时 `Ctrl+F5`）。明火页应显示 `YOLOv8n Fire / 320`、检测运行中、实际检测帧率，且画面方向正确。把启用脚本的推理耗时及此页状态记录下来。
2. 在无火环境观察至少 2 分钟，检查暖色物体、LED、玻璃反射是否误报。
3. 先用火焰图片或视频在镜头前验证标框、连续确认及通知闭环，记录为“屏幕回放测试”。不要把它计作实际火焰检测验收。
4. 移开火焰画面后保持有效无火画面至少 15 秒，检查恢复事件及声光复位。
5. 测试异常持续、遮挡与拔掉摄像头：持续异常不刷事件；画面中断显示未知，已有报警不能自动恢复。重新插入后验证重新采集。
6. 关闭浏览器再触发一次，检查后台事件与邮件。最后记录小火焰实际场景与反光的误报、漏报及延迟；若进行实火测试，远离纸张、导线和塑料，不在封闭玻璃罩内点火。

本机测试已经验证模型可执行、类别映射、确认/恢复规则及网页流程。树莓派吞吐、温度、长期稳定性和实景准确率尚待用户实测。

## 检查与停用

只检查本地模型，不联网、不改配置：

```bash
cd /home/pi/factory_monitoring && .venv/bin/python deploy/raspberry-pi/setup_vision.py --check-only
```

需要暂停检测时在 `deploy/raspberry-pi/runtime.env` 将 `FACTORY_VISION_ENABLED=1` 改为 `0` 后重启。暂停检测不会自动抹去尚未确认恢复的明火报警；恢复检测并取得连续无火画面后再解除。

模型来源与边界见 [模型说明](../models/README.md)；训练模型和运行模型是不同工作，本阶段为第三方模型部署与系统联动。
